ブラウザの中だけにある架空のフォルダを操作します。ターミナルを一度も触ったことがない人向けです。「今どこにいる？」から始め、最後はヒントだけを頼りに自力で一連の操作を組み立てます。進捗はこのブラウザに自動保存されます。
練習用ターミナル — 安全な仮想環境
$
使えるコマンド
pwd 今いる場所 / ls 中身を見る / cd 移動 / mkdir フォルダ作成 / touch ファイル作成 / cat 中身表示 / echo 文字を出す・書く / cp コピー / mv 移動・名前変更 / rm 削除 / grep 文字検索 / clear 画面を消す / help ヘルプ
実際のターミナルと同じように、キーボードの ↑ ↓ で入力履歴、Tab でコマンド名や現在のフォルダ内の名前を補完できます。
