# command-line-beginner-simulator

ターミナルを一度も触ったことがない人向けの、日本語ハンズオン型コマンドラインシミュレータです。

ブラウザ内の安全な仮想ファイルシステムで、19ステップを順番に体験できます。

## 学べること

- 現在地の確認とフォルダ移動: `pwd` / `cd` / `..` / `~`
- 相対パスと絶対パス
- ファイルとフォルダの基本操作: `ls` / `mkdir` / `touch` / `cat` / `cp` / `mv` / `rm`
- 隠しファイルとコマンドのオプション: `ls -a`
- テキスト出力と保存: `echo` / `>` / `>>`
- コマンドの調べ方: `--help`
- スペースを含む名前の扱い: 引用符
- テキスト検索: `grep`
- コマンドの連結: `|`
- 最後に、入力候補なしで基本操作を組み合わせる総合演習

## 学習を支える機能

- 進捗と仮想ファイルシステムをブラウザ内に自動保存し、次回その続きから再開
- アプリ更新後も同じ保存データを引き継ぎ、旧v4形式の進捗も自動移行
- 現在のステップだけを開始状態へ戻す機能と、全体を最初からやり直す機能
- 実際のターミナルに近い `↑` / `↓` のコマンド履歴
- キーボードの `Tab` とスマホ用「Tab補完」ボタンによる入力補完
- `../` / `~/` / 絶対パスを含むパス途中でもTab補完
- `ls` / `mkdir` / `touch` / `cat` / `cp` / `mv` / `rm` / `grep` などで相対パス・絶対パス・`~` を利用可能
- `a | b | c` のように3つ以上のコマンドもパイプで連結可能
- コマンド名を打ち間違えたときの候補表示
- エラーになったコマンドでは学習ステップをクリア扱いにしない判定

実機のファイルを変更しないため、失敗を気にせず練習できます。
